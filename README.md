## 🧠 How I like to learn

I learn best by **building things**.

I don't particularly enjoy memorising syntax just for the sake of memorising syntax. I'd rather have a problem, investigate it, break something, read the documentation, look at the source code and eventually figure out what's going on.

Sometimes this produces useful software.

Sometimes it produces a kernel.

Sometimes it produces both a useful software project and a kernel-shaped headache.
